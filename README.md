 🏦 Bank Management System

A Python-based Bank Management System designed to manage customer accounts and perform essential banking operations.

 📌 Project Overview

This project is developed using Python to understand and implement real-world programming concepts. It provides basic banking functionalities such as account creation, deposits, withdrawals, balance checking, and customer account management.

The project demonstrates Object-Oriented Programming (OOP), JSON data storage, file handling, input validation, and exception handling.

 ✨ Features

- Create a new bank account
- Generate unique account numbers
- Deposit money
- Withdraw money
- Check account balance
- Manage customer account details
- Store account data using JSON
- Input validation and exception handling

 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling
